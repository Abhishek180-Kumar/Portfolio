Working Method

How I build.

01

Understand the problem

Before writing code, I work out who uses the product, what the workflow is, and what "done" looks like.

02

Design before coding

Schema, roles and API contracts come first. GoanMart's role-based backend was planned as a schema before any endpoints were written.

03

Ship and verify

I deploy working versions early and verify them with tests, CI checks and manual test-mode payment runs before going live.

04

Fix what breaks

Bugs like a silently dropped Mongoose field or a webhook race condition were found by testing, then fixed with focused pull requests.
