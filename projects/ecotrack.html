EcoTrack

An applied computer-vision project: a CNN trained to sort waste into Organic, Recyclable and Hazardous categories, deployed as a Streamlit app for real-time image inference.

01 — Dataset & Problem

Sorting waste correctly, automatically.

Manual waste sorting is error-prone and inconsistent. EcoTrack frames this as a straightforward image-classification problem: given a photo of an item, predict which of three bins it belongs in — Organic, Recyclable, or Hazardous. Dataset details to be documented.

02 — Model

A CNN built for the task, not for scale.

The classifier is a convolutional neural network built with TensorFlow — sized and scoped for a three-class problem rather than an open-ended one. This was intentionally kept as an applied project demonstrating the full pipeline, not a research-scale system.

03 — Training

Training and evaluation.

The model was trained and validated on labeled image data across the three target categories, with standard train/test evaluation used to check generalization before deployment.

04 — Evaluation

~92% accuracy.

On held-out test data, the model reaches approximately 92% classification accuracy across the three categories — a solid result for a single-developer applied CV project, with room for improvement on ambiguous or mixed-material items.

05 — Inference & Deployment

Shipped as a Streamlit app.

The trained model is deployed behind a Streamlit interface: upload an image, get a real-time prediction. Streamlit was chosen specifically to get a usable, demoable interface without building a separate frontend for what is fundamentally a model-serving task.

06 — Lessons Learned

The gap between "a model that scores well on test data" and "a model that's actually pleasant to use" is mostly about the interface around it — clear feedback, fast inference, and honest handling of low-confidence predictions rather than a false-confident answer.
